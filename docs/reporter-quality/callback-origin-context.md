# Original questions in due callbacks

E08 adds first-version context to the automatic storyline review pool. That pool
excludes arcs already delivered through a due callback, whose linked summary
currently carries only the current version. In the completed season, the added
projection covered 17 of 37 successful storyline updates; six more already had
first-version context, while 14 did not. A later known-failure challenge repeated
a false historical summary through this omitted path.

This extension attaches the same bounded, read-only original context to storylines
already shown inside due callbacks. It does not select more callbacks, broaden
retrieval, change due ordering, create new write selectors, or alter source,
verification or mutation semantics. Existing current handles remain bound to their
current pinned versions. The original question is a hypothesis to verify, not
current factual authority or required article coverage.

The same first-version inspection boundary and clipping limits apply: 200 headline,
2,000 summary and 400 callback-condition characters. Version one needs no duplicate
projection; filtered history never substitutes a later version. An unavailable
history lookup leaves the current callback visible with an explicit notice and
partial-recall telemetry. The review-pool projection remains unchanged.

Offline tests cover exact historical binding, current-handle updates, old pins,
filtered introductions, version-one omission, clipping, explicit focus and lookup
failure. All 45 targeted tests passed on both the clean candidate and operational parent.
Offline correctness does not demonstrate better narrative use.

The registered challenge reused the preserved earlier control and its exact
pre-generation state for one treatment. The control is a known failure,
not a newly sampled independent arm. Judge exact delivery separately from source
research, newly saved historical claims and the original question's lifecycle.
A corrected title or more cautious callback date alone is insufficient. No target
identity or desired answer is added to reporter instructions, and no failed scope
paragraph is inherited. Retain omission, failure and inconclusive outcomes without
rerolls; decide on further measurement only after the result is inspected.
